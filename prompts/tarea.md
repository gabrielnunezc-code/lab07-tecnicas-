# Tarea: Mi prompt avanzado
## Tarea elegida
La tarea que escogi fue un sistema que me permita registrar pedidos de una cafeteria en POO de java.
## Version 1: prompt basico
**Genera un codigo de POO en el que pueda registrar pedidos de una cafeteria**
- En este promp la ia respondio con el codigo, no explico que hacia cada cosas pero si explico que era, donde estaba ubicado todo, la clase principal, etc.
## Version 2
**Actua como un profesor de POO en java, y explicame como puedo diseñar un codigo de POO en el que pueda registrar pedidos de una cafeteria**
- Aqui aplicamos el role prompting. Aqui la Ia fue paso a paso, explicado cada cosa y siendo más lago tambien.
## Version 3: prompt final
**Actúa como un profesor de Programación Orientada a Objetos (POO) especializado en Java y enséñame, paso a paso, cómo diseñar y desarrollar un sistema para registrar pedidos de una cafetería.Quiero aprender POO mientras construimos el proyecto, así que no te limites a darme el código terminado. Explícame primero cómo analizar el problema y cómo identificar las clases, atributos, métodos y relaciones entre objetos.
Y no me entregues todo de una sola vez.**
- En esta Parte el codigo es mucho más grande y especifico, enfocado en la enseñanza más que todo. Aqui la IA va paso a paso explicando todo.
## Tecnicas usadas en el prompt final
Asignación de rol (Role Prompting)

“Actúa como un profesor de Programación Orientada a Objetos (POO) especializado en Java…”

Le das a la IA un rol específico para influir en el tipo de respuesta, nivel de explicación y enfoque pedagógico.

Contextualización

“…enséñame… cómo diseñar y desarrollar un sistema para registrar pedidos de una cafetería.”

Defines el contexto del problema. Esto evita que la explicación de POO sea completamente abstracta y permite aprender mediante un caso práctico.

Aprendizaje basado en proyectos (Project-Based Learning)

“Quiero aprender POO mientras construimos el proyecto…”

No pides estudiar teoría de manera aislada, sino aprender los conceptos mientras se desarrolla un proyecto real.

Descomposición paso a paso (Step-by-Step)

“enséñame, paso a paso…”

Le indicas que divida el proceso en etapas en lugar de entregar una solución completa de inmediato.

Andamiaje pedagógico (Scaffolding)

“Explícame primero cómo analizar el problema y cómo identificar las clases, atributos, métodos y relaciones entre objetos.”

Esta es una técnica especialmente importante. Estableces una secuencia de aprendizaje: primero análisis → después diseño → posteriormente implementación.

Restricción de la respuesta

“no te limites a darme el código terminado.”

Estás restringiendo un comportamiento que no deseas: que la IA simplemente genere la solución final.

Aprendizaje por razonamiento/diseño antes del código

“Explícame primero cómo analizar el problema…”

Estableces una regla de “primero comprender, después implementar”. La IA debe trabajar primero el modelo conceptual antes de pasar a Java.

Control de la cantidad de información

“Y no me entregues todo de una sola vez.”
